# Feature: Usability testing

**From build-plan:** feature 18
**Status:** not started

## Goal

Validate that target users can find answers quickly, understand the guidance, navigate the app, and trust the safety-first ordering. Produce a documented test plan, session guide, and findings log that feed later fixes.

## In scope

- Test plan with target participant profiles, tasks, success criteria, and metrics.
- Moderated session guide with consent, scenario prompts, and think-aloud instructions.
- Findings template and a first completed findings log.
- Prioritized fix list mapped to build-plan items.

## Out of scope

- Automated analytics, A/B testing, or remote unmoderated tools.
- Production instrumentation.
- Recruiting logistics beyond the plan.

## Build steps

- [ ] **Step 1 - Test plan** - create `buildflow/usability/test-plan.md` with profiles, tasks, success criteria, and metrics.
- [ ] **Step 2 - Session guide** - create `buildflow/usability/session-guide.md` with consent, prompts, and scoring sheet.
- [ ] **Step 3 - Findings log** - create `buildflow/usability/findings.md` template and record the first run's findings.
